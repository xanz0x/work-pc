**Проблема одной строкой.** Статус-бар обещает «ЛОКАЛЬНЫЙ РЕЖИМ · 0 УТЕЧЕК», а в облако
уходит индекс всех файлов (имена, категории, теги).

**Файлы.** `app/ai-api/chat/route.ts` · `components/screen-chat.tsx` (buildCtx)
· `lib/vault-store.tsx` (settings.engine, stats) · `components/app-shell.tsx`

**Шаги.**
1. В route принимать заявленный режим и проверять его на сервере: `engine=local` → сразу
   ответ-ошибка «локальный движок не подключён» без единого внешнего запроса.
2. Добавить настройку «не отправлять индекс сейфа»: при включении `ctx.files` не собирается,
   уходят только закреплённые файлы.
3. Первый облачный запрос в сессии → модалка согласия со списком того, что уйдёт
   (имена файлов, теги, текст запроса). Согласие хранить в настройках.
4. На каждый облачный ход писать событие в ленту: «в облако ушло N имён файлов»,
   `cat: 'privacy'`, `link: {kind:'screen', id:'chat'}`.

**Готово когда.** При `engine=local` внешних вызовов нет; в облачном режиме пользователь
один раз дал согласие и видит запись в ленте; ни один лейбл не противоречит факту.

**Не делать.** Не удалять облачный режим и не менять дизайн чата.
