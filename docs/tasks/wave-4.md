- Сторы получили порционные операции (`bulkPatchFiles`, `bulkRemoveFiles`,
  `restoreFiles`, `bulkPatchNotes`, `bulkPatch`, `bulkPurge`, `bulkRestore`):
  одна запись в хранилище на порцию вместо 500 записей на объект.

Ctrl/Shift-выделение, секреты, перенос в папку, файловый ключ на группу).

`test_reports/iteration_18.json`: на корпусе из 500 файлов выбор даёт 504
объекта, прогресс идёт (замеры 75 и 225 из 504 в середине), клик по чужой
кнопке во время операции работает, «Отмена» останавливает на 350 из 504 —
в хранилище ровно 350, «Вернуть» откатывает до нуля. Весь каталог e2e зелёный
(34 passed, 0 failed).

_Найдено и исправлено на приёмке._ «Выбрать всё в фильтре» выделяло только
нарисованную страницу доски (разделены `markOrder` и `filterOrder`); подпись
окна возврата читалась как «уже сделано» (теперь «Можно вернуть: …»); сброс
состояния по `lockEpoch` срабатывал при монтировании экрана и гасил только что
открытую модалку (теперь реагирует лишь на настоящую смену эпохи замка).

## NF-6 · Командный центр в палитре `P2` `DONE` 2026-09-02

**Файлы.** `components/command-palette.tsx` · новый `lib/commands.ts`
· новый `tests/unit/commands.test.ts` · `tests/e2e/14-bulk-and-commands.spec.ts`
· `components/screen-library.tsx`, `components/screen-vault.tsx` (намерения экранов)

**Шаги.** Реестр команд (действия, переходы, настройки, недавнее); поиск по сущностям
остаётся первой группой; у каждой команды подсказка и доступность по контексту.

**Готово когда.** Не меньше 20 команд работают с клавиатуры из любого экрана.

**Статус — `DONE` 2026-09-02.**

_Сделано._
- `lib/commands.ts` — 33 команды в трёх группах: действия (20), переходы (6),
  настройки (7). У каждой заголовок, подсказка, иконка, слова для поиска;
  у условных — предикат доступности и человеческая причина отказа
  («сейф секретов закрыт», «папка не подключена»). Контекст (`CommandCtx`)
  собирает палитра из сейфа — реестр ничего не знает о React.
- «Намерения»: команда, живущая внутри экрана (композер стикера, генератор
  пароля, импорт/экспорт, режим выделения), переключает экран и оставляет
  заявку; экран подхватывает её при монтировании. Поэтому команда работает
  из любого места, а не только там, где кнопка нарисована.
- Палитра: первая группа при запросе — сущности сейфа (тот же store, что у
  топбара), дальше группы команд; при пустом запросе — «Недавнее» из
  localStorage (`wf.commands.recent.v1`) и весь реестр. Курсор ходит только по
  запускаемым строкам (↑↓, Home/End, Enter), недоступная команда видна с
  пометкой «недоступна» и объяснением.
- Клавиатура: Ctrl/Cmd+K из любого экрана (хоткей был в `lib/store/nav.tsx`),
  подсказка сочетания у команды, у которой оно есть (Ctrl+Shift+L — замок).

_Проверено._ `tests/unit/commands.test.ts` (состав реестра, уникальность id,
доступность по контексту, поиск, запуск) и e2e: палитра открыта с библиотеки,
карты, чата, секретов, центра активности и настроек — везде 33 команды; поиск +
Enter включает режим выделения в библиотеке; недоступная команда объясняется
тостом; «Недавнее» переживает перезагрузку.

_Найдено и исправлено на приёмке._ Esc и первые буквы, нажатые сразу после
Ctrl+K, терялись (фокус ставился через `setTimeout` 20 мс) — теперь фокус
синхронный с подстраховкой rAF; Esc и стрелки не работали, если фокус уходил
из поля (клик по чипу области, Tab) — обработчик клавиш переехал с поля ввода
на окно палитры.
