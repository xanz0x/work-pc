# Как начинать сессию работы над WorkfloW

Короткая инструкция для себя. Читать целиком — 40 секунд.

## 1. Сориентироваться (2 файла, не больше)

1. `docs/tasks/README.md` — доска: какая волна активна и какая задача следующая.
2. Блок конкретной задачи в `docs/tasks/wave-N.md` — там цель, файлы, шаги, критерий готовности.

Аудит (`docs/audit/`) перечитывать не нужно: всё, что из него следует, уже разложено
по задачам. Открывать только если задача противоречит здравому смыслу.

## 2. Проверить, что среда живая

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:3000/   # 200
npx tsc --noEmit                                                   # 0 ошибок
```

Если фронтенд не поднят: `sudo supervisorctl restart frontend`.
Процесс `backend` в BACKOFF — это норма (см. `backend/README.md`).

## 3. Правила, которые экономят время

- Дизайн-систему (`app/globals.css`) не переписывать: только добавлять слой в конец.
- Крипто-ядро (`lib/crypto-vault.ts`, `lib/secrets-crypto.ts`, `lib/lock-migrate.ts`)
  не трогать без явной задачи; менять — только с тестом.
- Внешний API `useVault()` сохранять: экраны на него опираются повсеместно.
- Ключи `localStorage` (`wf.*`) не переименовывать без миграции.
- Новая зависимость — по умолчанию нет. Продукт zero-dependency там, где это возможно.
- Любая цифра в UI должна иметь источник. Нет источника — «—», а не выдуманное значение.
- Данные пользователя не удаляются необратимо без подтверждения или окна отмены.

## 4. Закончить задачу

```bash
npx tsc --noEmit && npx next build      # типы и сборка
```

1. Прогнать вручную сценарий, который задача затрагивает.
2. Поставить `DONE` + дату в блоке задачи и в сводной таблице `docs/tasks/README.md`.
3. Обновить `memory/PRD.md` — один абзац на завершённую волну, не на каждую задачу.
4. Если создавались тестовые доступы — записать в `memory/test_credentials.md`.

## 5. Когда останавливаться и спрашивать

- Меняется схема замка или требуется миграция существующих данных.
- Меняется продуктовая концепция или обещание приватности.
- Нужен новый внешний сервис, аккаунт или платный ключ.
- Задача требует удалить пользовательские данные или функциональность.
