## Раздел 4 — Предпросмотр библиотеки (как в Notion)

- **«Открыть» починено**: кнопка инспектора теперь открывает просмотрщик
  (`insp-preview`), раньше показывала только тост.
- **Просмотрщик** `components/library-viewer.tsx`:
  - текст/код — читаемо, моноширинно, с копированием (лимит превью 512 КБ);
  - markdown — отрендеренный (тот же AiMarkdown);
  - PDF — встроенно (iframe по blob-URL); изображения — встроенно;
  - аудио/видео — плеером;
  - ZIP — список содержимого с извлечением: текстовые записи показываются
    в просмотрщике, бинарные скачиваются;
  - неподдерживаемые форматы — честная заглушка + действия;
  - скелетон загрузки, переходы, hover-состояния (`cloud-viewer.css`).
- **Серверный мини-роут** `app/ai-api/cloud/zip/route.ts`:
  POST `{objectId}` → список записей; POST `{objectId, entry}` → содержимое
  записи (adm-zip на сервере; лимит записи 25 МБ, 2000 записей в списке).
- **Источники байтов**: общий диск — объектный роут
  `/ai-api/cloud/file/[id]` (по cloudId, включая cloudCopies локального
  файла); локальный файл — оригинал из `lib/indexer/originals.ts`
  (FSA-хэндл). Локальный ZIP без общей копии — честная заглушка
  (распаковка живёт на сервере).
- **Действия моста**: «Открыть на ПК» → `window.workspacexDesktop?.openPath(absPath)`,
  «Показать в папке» → `revealInExplorer(absPath)` — в шапке просмотрщика,
  инспекторе и контекст-меню; при отсутствии моста или absPath кнопка
  задизейблена с подсказкой «Доступно в приложении для Windows». absPath
  читается опционально из метаданных объекта (поле появится у другого
  исполнителя).
- Файлы под файловым ключом: просмотр сначала требует ключ (как из сетки).
