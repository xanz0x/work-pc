## 1. Папка хранения по умолчанию
- В разделе «Библиотека/Общий диск» появляется «Папка хранения»: пользователь указывает путь на ПК.
- Путь валидируется серверно (существует/создаётся), сохраняется в `<AI_DIR>/cloud/storage-root.json`.
- Все новые загрузки: байты файла физически перемещаются/записываются в эту папку под исходным именем (коллизии — `имя-1.ext`), метаданные (sha256, имя, размер, mime, относительный путь) — в существующем хранилище.
- Старые объекты в `data/cloud/objects` остаются читаемыми (обратная совместимость).
- Кнопка «Открыть папку» → `window.workspacexDesktop?.revealInExplorer(path)` (мост делает другой исполнитель; вызов через optional chaining).

## 2. Анализ каждого добавленного файла
- При добавлении любого файла запускается серверный конвейер анализа (асинхронно, со статусом в UI).
- Текст/код/MD — читается напрямую; PDF — pdf-parse; DOCX — mammoth; ZIP — adm-zip: список содержимого + извлечение текста внутренних файлов (лимиты: ≤2 МБ на файл, ≤10 файлов).
- Изображения — exifreader (EXIF, размер, дата, камера) + vision-модель **moondream**: если её нет в `/api/tags` — скачивается через Ollama по требованию, затем описание через `/api/chat` с картинкой.
- Описания документов — qwen2.5:3b: точное название (≤8 слов) + описание (≤40 слов) содержимого.
- Результат: `title`, `description`, `kind`, `analyzedAt` в метаданных объекта; в библиотеке показываются название (сгенерированное) + оригинальное имя, спиннер «Анализ…», кнопка «Переанализировать».

## 7. Мост Electron (контракт для всех)
`desktop/src/preload-workspace.cjs` → `window.workspacexDesktop = { openExternal(url), revealInExplorer(absPath), openPath(absPath) }`:
- openExternal — только http(s);
- пути — только внутри папки хранения (`storage-root.json`); reveal — `explorer /select,`, open — `shell.openPath`;
- preload подключается в `openWorkspace()` (sandbox, contextIsolation); `setWindowOpenHandler` workspace-окна: внешние URL → `shell.openExternal`, окно не создавать.
