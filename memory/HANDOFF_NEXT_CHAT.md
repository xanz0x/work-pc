# Передача следующему чату (2026-06, сессия «подпапки + меню письма»)

Все пять задач из `docs/tasks/NEXT-CHAT-INSTRUCTIONS.md` закрыты, проверены E2E и убраны за собой.
Подробности — `memory/PRD.md` (последний раздел) и `memory/NEXT_SESSION.md`.

## Коротко
- Подпапки: файл ложится в НАСТОЯЩУЮ подпапку выбранной папки на ПК (`<root>/A/B/файл`),
  остаётся личным (`shared:false`), в общий диск сам не уезжает и не дублируется.
  В Библиотеке — полоса папок с крошками и честной фильтрацией.
- Кнопка «Добавить файл» в левом меню теперь тоже проходит через диалог подпапки (раньше нет).
- Контекстное меню внутри письма работает по CTA/ссылке, обычному и выделенному тексту и по
  картинке; картинки писем временной почты наконец грузятся (`data:`-URI вместо прокси в `src`).
- vitest полностью зелёный: 327/327 (в `/app/desktop` нужно `pnpm install --prod`).

## Ловушки среды
- После сброса пода нет `node_modules` и `.env.local` — восстанавливать оба (см. NEXT_SESSION.md).
- Смена `MAIL_SECRET` обнуляет доступ к прежним временным ящикам.
- Приложение — прод-сборка Next.js под supervisor `frontend`; свои dev-серверы не запускать.
- `/tmp` не durable; тестовые каталоги делать в `/root/...` и удалять после теста.
