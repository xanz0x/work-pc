# Тестовые доступы

Приложение полностью локальное (localStorage), аккаунтов и сервера нет.
Единственный «доступ» — мастер-ключ замка, который создаётся в браузере пользователя.

## Мастер-ключ для тестов (создать вручную в чистом профиле)
1. Сайдбар → «Менеджер секретов» → «Настроить мастер-ключ»
   (или Настройки → Безопасность → «Настроить мастер-ключ»).
2. Метод: **Пароль**.
3. Пароль: `test-master-1234` (двойной ввод).

При смене мастера в сценариях используется `new-master-9876`.

Пароль экспорта/снимка в тестах: `backup-pass-2026`.
Тестовый TOTP-секрет: `JBSWY3DPEHPK3PXP` (Base32, 6 цифр, период 30с).
Пример файла импорта: CSV в стиле KeePassXC (колонки Group,Title,Username,Password,URL,Notes,TOTP).

Важно: замок живёт в localStorage конкретного профиля браузера.
В новом профиле/новой сессии тестов мастер-ключ нужно создавать заново.

## Данные для сценариев v1.5
Wi-Fi для QR: SSID `HomeNet`, пароль `p@ssw0rd!123`; кириллический вариант — SSID `Кафе-Гуща`,
пароль `Секрет;пароль:1` (проверяет экранирование `;` и `:` в payload WIFI:).
Вложения: файл ~2 КБ с маркером `PLAINTEXT-MARKER-42` (маркера не должно быть в
localStorage['wf.secrets.v1']); проверка лимита — файл 400 КБ (ожидается `attach-error`).
