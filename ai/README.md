# AI-папка WorkfloW

Все настройки встроенного ИИ лежат здесь физическими файлами и редактируются
через UI (экран «Чат с ИИ» → «AI-центр»).

- `system.md` — базовый системный промпт модели (Claude Sonnet 4.5 через шлюз Emergent).
- `skills/*.json` — скиллы: встроенные инструменты (`kind: "tool"`) и
  пользовательские инструкции (`kind: "prompt"`). Поле `enabled` выключает скилл.
- `mcp/*.json` — конфиги MCP-серверов (Notion — пока скелет: до реального
  токена ответы имитируются).
- `sessions/*.json` — сохранённые диалоги: снимок сообщений для UI (`msgs`)
  и сырая история для модели (`llm`).
