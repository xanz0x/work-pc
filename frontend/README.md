# frontend/ — лончер для предпросмотра

Приложение — это Next.js в корне репозитория. Supervisor предпросмотра ожидает
фронтенд в `/app/frontend`, поэтому здесь лежит только `package.json`, который
поднимает `next dev` из корня на `0.0.0.0:3000`.

Локально этот каталог не нужен: `pnpm dev` из корня делает то же самое.
