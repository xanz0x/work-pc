# Тесты

## `api/test_ai_api.py`

Интеграционные тесты серверных маршрутов Next.js (`/ai-api/skills`, `/ai-api/mcp`,
`/ai-api/system`, `/ai-api/sessions`, SSE-поток `/ai-api/chat` с циклом скиллов).

```bash
pip install pytest requests
APP_URL=http://localhost:3000 python3 -m pytest tests/api -q
```

`APP_URL` — адрес запущенного приложения (по умолчанию `http://localhost:3000`),
`AI_DIR` — каталог файлового слоя ИИ (по умолчанию `/root/.workflow/ai`, вне репозитория),
`APP_PASSWORD` — пароль приложения: с волны 1 весь `/ai-api` закрыт сессией, и
фикстура `api` сначала логинится через `POST /ai-api/auth/login`.

## `api/test_wave1.py`

Тесты волны 1 «Правда и безопасность»: 401 без cookie, вход и выход, 409 при
`engine=local` (внешних запросов нет), 429 после 10 ходов в минуту, отсутствие
имён переменных окружения и секрета MCP в ответах.

Лимит чата — 10 ходов в минуту на IP, поэтому подряд идущие прогоны чата
честно получают 429: между запусками нужна пауза около минуты.

Тесты пишут и удаляют собственные скиллы и сессии, но проверяют и встроенные:
запускать против рабочего сейфа с ценными диалогами не стоит.
