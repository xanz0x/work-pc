# Тесты

Три уровня, все три обязательны перед закрытием задачи.

```bash
pnpm lint          # eslint (правила Next)
pnpm typecheck     # tsc --noEmit
pnpm test          # unit, Vitest
pnpm test:api      # интеграционные, pytest (нужно запущенное приложение)
APP_URL=http://localhost:3000 APP_PASSWORD=... pnpm test:e2e   # Playwright
```

## `tests/unit/*` · Vitest

Чистая логика без DOM: крипто-ядро замка (`crypto-vault`), портируемые снимки
секретов (`secrets-crypto`), переупаковка ключей (`lock-migrate`), аудит замка
(`lock-store`), раскладка доски, TTL стикеров, redact-слой поиска, модель
уведомлений, окно контекста диалога, слой IndexedDB (в том числе миграция схемы
v1→v2 и перелив из localStorage), валидация env и фильтр PII в логе.

Окружение — node. `tests/unit/setup.ts` подкладывает `fake-indexeddb` и
Map-реализацию `localStorage`: крипто-ядро и слой хранилища их ожидают.

Тест `крипто-ядро замка › политика KDF не откатывается ниже 600 000` — намеренный
предохранитель: ослабление крипты роняет `pnpm test`.

## `tests/api/*` · pytest

- `test_ai_api.py` — маршруты скиллов, MCP, системного промпта, сессий и SSE-чата.
- `test_wave1.py` — 401 без cookie, вход и выход, 409 при `engine=local`, 429 после
  10 ходов в минуту, отсутствие имён переменных окружения в ответах.
- `test_wave2.py` — `X-Request-Id` на каждом ответе, 400 на битый JSON и
  недопустимый `sessionId`, локальный трекер ошибок и четыре метрики без утечки
  содержимого запросов.

Переменные: `APP_URL` (адрес приложения), `AI_DIR` (файловый слой ИИ, по умолчанию
`/root/.workflow/ai`), `APP_PASSWORD` (весь `/ai-api` закрыт сессией).

Лимит чата — 10 ходов в минуту на IP: подряд идущие прогоны честно получают 429,
поэтому `test_wave2.py` один раз ждёт окно и повторяет запрос.

## `tests/e2e/*` · Playwright

Пять сценариев: настройка замка и разблокировка, приём файла, ход диалога с
облачной моделью, создание записи в менеджере секретов, уведомления
read/unread/архив. Сценарий диалога пропускается без `APP_PASSWORD` — вместо
имитации зелёного результата.

```bash
npx playwright install chromium   # один раз
```

## CI

`.github/workflows/ci.yml`: lint + typecheck + unit + build на каждый PR.
API- и E2E-прогоны требуют запущенного приложения и в гейт не входят.
