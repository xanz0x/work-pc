# Сторонние компоненты

- Electron, Next.js, React: MIT; собственные notices зависимостей сохраняются в сборке.
- Локального ИИ-движка и весов моделей в продукт не входит: модель подключает
  владелец в настройках (OpenRouter или свой OpenAI-совместимый сервер).
  Условия использования конкретной модели определяет выбранный провайдер.
- SmailPro/Sonjj: отдельный внешний сервис с собственными условиями и лимитами. Ключ вводится только владельцем главного ПК.

Установщик без сертификата подписи издателя может вызвать предупреждение Windows SmartScreen. HTTPS-сертификат приложения идентифицирует главный ПК и не является подписью установщика.
